# AMetric Toolbox — Download e aggiornamenti

Suite di strumenti per l'ingegneria strutturale secondo NTC 2018, per
Windows 10/11 (64 bit):

- Carichi variabili NTC 2018 (neve, vento, temperatura)
- Spettri sismici NTC 2018
- Sezioni rettangolari in c.a.
- Coordinamento attività
- Isolatori sismici HDRB — modulo a pagamento
- Sezioni generiche in c.a. (beta) — modulo a pagamento

I primi quattro sono gratuiti per sempre. Al primo avvio si attiva con la
propria e-mail una prova gratuita di 30 giorni, che sblocca anche i moduli a
pagamento.

**Sito ufficiale:** [www.ametric-strutture.com](https://www.ametric-strutture.com/toolbox/)

## Download

➡️ **[Scarica l'ultima versione](https://github.com/ametric-strutture/ametric-toolbox-releases/releases/latest/download/AMetric_toolbox_setup.exe)**

L'installazione non richiede privilegi di amministratore. Una volta
installato, il software si mantiene aggiornato da solo: a ogni avvio
verifica la disponibilità di una nuova versione e la installa
automaticamente alla chiusura.

Dalla versione 1.2 l'installer è **firmato** con un certificato di code
signing intestato ad Andrea Mercurio. Ogni release contiene anche il file
`.sha256` con l'impronta dell'installer: per controllarla, in PowerShell,
`Get-FileHash AMetric_toolbox_setup.exe`.

Questo repository ospita esclusivamente i file di installazione
(sezione [Releases](https://github.com/ametric-strutture/ametric-toolbox-releases/releases)).
Per assistenza: [mercurio@ametric-strutture.com](mailto:mercurio@ametric-strutture.com)
